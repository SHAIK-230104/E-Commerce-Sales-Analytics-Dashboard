# 📊 E-Commerce Sales Analytics Dashboard

An interactive **E-Commerce Sales Analytics Dashboard built using Microsoft Excel** to analyze revenue, orders, customers, products, categories, and sales trends.

This project demonstrates practical skills in **data analysis, KPI development, Excel formulas, data visualization, and dashboard design**.

\---

## 🎯 Project Overview

The goal of this project was to transform raw e-commerce sales data into a clean, visually engaging dashboard that helps users understand business performance and identify important sales trends.
